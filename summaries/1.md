# Problems Encountered

Several bugs and gaps were discovered during analysis:

1. **products/signals.py never registered** — `products/apps.py` lacks `ready()` importing signals, so low-stock email alert is dead code. Contrast with `orders/apps.py` which correctly imports signals.

2. **`ProductVariantSerializer.discount_percentage` runtime error** — declared as `ReadOnlyField()` but no `discount_percentage` property exists on `ProductVariant` model. Will crash when serializing variants.

3. **`RecommendationEngine.get_similar_products` attribute mismatch** — references `product.categories` (M2M) but `Product.category` is a single FK. Will raise `AttributeError` when called.

4. **`recommendations` app not mounted** — missing from `config/urls.py`, all recommendation endpoints unreachable.

5. **`Coupon.used_count` never incremented** — `Order.coupon` and `discount_amount` fields exist but checkout flow ignores coupons entirely; `shipping_cost=25` is hardcoded.

6. **`Product.sales_count`/`view_count` never incremented** — these fields exist on the model but no signal or view action updates them.

7. **`production.py` is empty** — no CORS override, no SECURE_PROXY_SSL_HEADER, no DEBUG env-config, no LOGGING, no SMTP configuration. Violates deployment hardening rules.

8. **No `manualChunks` in vite.config.js** — both frontends lack vendor bundle splitting (minor).

9. **Stray root artifacts** — `IMG_3383.PNG` (2.3MB), `deployment_package.zip` (4MB), `test_*.py`, `implementation_plan.md`, `plans/` directory.

10. **Dead dependencies** — Celery installed but no worker/beat configured; `django-smart-selects` and others may be unused.

# Important Context

## Architecture

```
root/
├── backend/          → Django 4.2 + DRF + SimpleJWT (9 apps)
├── frontend/         → Mature React/Vite SPA (storefront + /dashboard)
├── admin-dashboard/  → Skeleton React/Vite SPA (largely unfinished)
└── package.json      → Monorepo orchestration via concurrently
```

## Backend Apps (9)

| App | Role |
|---|---|
| accounts | Auth (no custom User), JWT login/refresh/me |
| products | Full catalog: Category, Brand, FragranceFamily, Product, ProductVariant, ProductNote, ProductImage |
| cart | Session-key + user carts with add/update/remove/clear actions |
| orders | Order workflow with status history, snapshots, email signals |
| cms | HeroSlide, Banner, StoreSettings (singleton) |
| marketing | Coupon CRUD + validate endpoint |
| crm | CustomerProfile (segment, tags, birth dedup), CustomerInteraction |
| analytics | Aggregate stats + inventory reports (no models) |
| recommendations | Similar products, bought-together, curated picks (NOT mounted in URLs) |

## API Prefixes

`/api/{accounts,products,orders,cart,crm,analytics,cms,marketing}/` — products has both `/api/products/` (public, slug-based) and `/api/products/admin/` (admin CRUD).

## Frontend — `frontend/` (Mature)

- React 18, react-router-dom v7, zustand (cart + theme persistence), axios w/ JWT refresh, framer-motion, i18next, tailwindcss v4, recharts
- 10 storefront routes + 10 protected `/dashboard/*` routes
- ProtectedRoute checks `localStorage.access_token` + `user.is_staff`
- Comprehensive API layer: `{products,orders,cart,cms,marketing,crm,adminProducts,analytics,accounts}Api`
- Orphaned pages: `DashboardBrands.jsx`, `DashboardCategories.jsx` (exist but not routed)

## Frontend — `admin-dashboard/` (Skeleton)

- Port 5174, same tech stack
- Only Dashboard.jsx is functional
- Categories.jsx is orphaned AND broken (calls missing API methods)
- /products, /orders, /customers are placeholders; /settings route missing
- store/, hooks/, utils/, components/dashboard, components/layout — all empty
- zustand + react-query imported but unused; auth interceptor commented out; logout button dead

- Arabic-first, RTL layout
- Luxury perfume store with gold/black theme
- Tailwind CSS v4
- Django as backend framework (per global rules)

- Django: Arabic verbose names (`verbose_name="المنتج"`)
