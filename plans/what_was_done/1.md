## Backend Changes

### `products` App
- Reconciled `Product` model with migrations: replaced `category` FK with `categories` M2M, removed `concentration`/`longevity_rating`/`sillage_rating`, added `occasion`/`vibe`, updated gender choices to `men/women/unisex`, made `brand` and `main_image` nullable.
- Added `Brand.slug`, made `Brand.logo` optional, added `Brand.Meta.ordering`.
- Added `ProductVariant.name`, made `size_ml`/`cost_price` nullable, made `sku` optional.
- Added `discount_percentage` property to fix the serializer crash.
- Updated serializers (`ProductListSerializer`, `ProductDetailSerializer`, `ProductVariantSerializer`) and added `AdminProductCreateSerializer` with writable PK fields.
- Updated `ProductViewSet` filters, queryset annotations, and `related` action to use `categories` M2M.
- Added `AdminCategoryViewSet`, `AdminBrandViewSet`, `FragranceFamilyViewSet`.
- Registered `products.signals` in `ProductsConfig.ready()`.
- Registered all product models in Django admin with inlines.

### `cms` App
- Added `HeroSlide.description_ar`.
- Removed `StoreSettings.shipping_cost` then re-added it via migration 0008 to keep shipping configurable.
- Added `StoreSettings.top_banner_is_active` and `top_banner_text`.
- Added `HomePageSection` model with `key`, `title_ar`, `content` JSONField, `is_active`, `order`.
- Fixed `StoreSettings.save()` to raise `ValidationError` instead of silently no-oping.
- Removed the broken `get_authenticators()` override; permissions now work correctly for staff GET requests.
- Added `HomePageSectionViewSet` and registered its route.
- Registered all CMS models in admin.

### `crm` App
- Changed `CustomerProfile.Meta.unique_together` to `(name, phone)` to match migration 0003.
- Added `ordering = ['-created_at']`.
- Made `CustomerInteractionSerializer.created_by_name` null-safe via `SerializerMethodField`.
- Added query optimization (prefetch + `annotate(interactions_count=Count(...))`) to `CustomerProfileViewSet` and `CustomerInteractionViewSet`.
- Fixed `add_interaction` to ignore client-supplied `customer`.
- Registered CRM models in admin.

### `orders` App
- Made `OrderItem.variant_size` nullable to match migration.
- Added `OrderCreateSerializer` for full input validation.
- Rewrote `OrderViewSet.create()`:
  - Uses `select_for_update()` on variants.
  - Keeps all money as `Decimal` (no float precision loss).
  - Applies coupon discounts and increments `Coupon.used_count` via `F()`.
  - Reads shipping cost from `StoreSettings`.
  - Generates unique order numbers with retry loop.
  - Updates customer stats with atomic `F()` expressions.
- Hardened `update_status`: validates status choices, sets `changed_by`, restores stock on cancel/return, wraps in atomic transaction.
- Secured `track` endpoint by requiring `phone` parameter.
- Added prefetches to `OrderViewSet.queryset`.
- Prevented duplicate confirmation email by skipping `pending` status-history email.
- Registered Order models in admin.

### `cart` App
- Disabled inherited `retrieve/update/destroy` actions to fix IDOR.
- Added input validation for `quantity` and stock checks in `add_item`/`update_item`.
- Added `CartItem.Meta.unique_together = ('cart', 'variant')` (with migration).
- Added prefetch in `get_cart()`.
- Registered Cart models in admin.

### `marketing` App
- Added `Coupon.Meta.ordering = ['code']`.
- Added `CouponValidateSerializer` to safely coerce `cart_total` to Decimal.
- Replaced fragile path-substring permission check with `self.action == 'validate'`.
- Registered `Coupon` in admin.

### `recommendations` App
- Created `RecommendationsConfig` in `apps.py`.
- Added `recommendations` to `LOCAL_APPS`.
- Mounted `/api/recommendations/` in `config/urls.py`.
- Removed unused `Category` import.
- Preserved frequency ordering in `get_bought_together`.

### `analytics` App
- Added prefetches to `recent_orders`.
- Converted ValuesQuerySets to `list()` before `Response`.
- Grouped top products by `variant__product_id` instead of name string.
- Removed unused imports.

### `config/settings`
- Filled `production.py` with CORS override, SSL/HSTS settings, Whitenoise static storage, logging, and SMTP configuration.
- Added `whitenoise` to requirements and middleware.
- Added `rest_framework_simplejwt.token_blacklist` to `INSTALLED_APPS`.
- Shortened `ACCESS_TOKEN_LIFETIME` to 15 minutes.
- Changed `wsgi.py` default settings module to `config.settings.production`.
