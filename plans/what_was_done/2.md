## Summary

Completed the second-round bug-fix plan. Fixed a critical stock-leak in the order creation flow, resolved storefront/admin product filtering mismatches, patched broken dashboard search debounce behavior, and cleaned up several backend/frontend warnings. All verification gates passed.

---

## Backend Changes

### `orders/views.py`
- **Fixed stock leak:** Moved stock deduction from the pre-order item loop to after the `Order` row is successfully created. Stock is now decremented atomically via `ProductVariant.objects.filter(...).update(stock_quantity=F(...) - qty)` only after `OrderItem` rows are created.
- If order-number generation fails (all 5 retries exhausted), the transaction now rolls back without deducting stock.
- Changed the order-number collision catch from `except Exception:` to `except IntegrityError:`.

### `orders/signals.py`
- Fixed Arabic typo in the order-confirmation email subject: "رق" → "رقم".

### `products/views.py`
- Changed `ProductViewSet` filterset to slug-based lookups:
  - `'categories__slug': ['exact']`
  - `'brand__slug': ['exact']`
- Updated `AdminProductViewSet`:
  - Changed `lookup_field` from `'slug'` to `'id'` to match the dashboard's numeric IDs.
  - Added `DjangoFilterBackend`, `SearchFilter`, and `OrderingFilter`.
  - Added `filterset_fields`, `search_fields`, and `ordering_fields`.
- Removed unused `status` import from `rest_framework`.

### `cms/views.py`
- Added `http_method_names = ['get', 'post', 'patch']` to `StoreSettingsViewSet` to prevent accidental singleton deletion.

### `marketing/views.py`
- Removed the dead first branch in `get_permissions`; kept only the `validate` action as public and everything else as admin-only.

### `analytics/views.py`
- Imported `Decimal` from `decimal`.
- Changed revenue aggregation fallbacks from `or 0` to `or Decimal('0.00')` to keep monetary values as decimals consistently.

### `config/settings/production.py`
- Removed deprecated `SECURE_BROWSER_XSS_FILTER = True` setting.

### `cart/views.py`
- Cached `self.get_cart()` in a local variable in `update_item` to avoid calling it twice.

## Frontend Changes

### `services/api.js`
- Changed `analyticsApi.getStats` to accept and forward params: `getStats: (params) => api.get('analytics/stats/', { params })`.

### `pages/dashboard/DashboardProducts.jsx`
- Fixed debounce effect: when already on page 1, calling `setCurrentPage(1)` was a no-op; now it calls `fetchProducts()` directly in that case.

### `pages/dashboard/DashboardOrders.jsx`
- Applied the same debounce fix, calling `fetchOrders()` directly when already on page 1.

### `pages/dashboard/DashboardCustomers.jsx`
- Applied the same debounce fix, calling `fetchCustomers()` directly when already on page 1.

### `pages/Products.jsx`
- Added `useSearchParams` and seeded filter state from URL `?category=` and `?brand=` query params.
- Renamed filter key `category` → `categories` to match the slug-based API filter.
- Hoisted `FilterSection` out of the component body into a separate component receiving props.

### `pages/dashboard/ProductEdit.jsx`
- Removed unused imports (`Tag`, `Upload`, `X`) from `lucide-react`.
- Added the missing `is_bestseller` checkbox in the display-options panel.

### `pages/dashboard/DashboardBrands.jsx`
- Fixed logo removal to clear `logo` instead of non-existent `image` field.

### `package.json`
- Removed dead dependencies `clsx` and `tailwind-merge`.
