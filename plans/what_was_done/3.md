## Summary

Completed the third-round plan. Removed dead backend dependencies and the CKEditor 4 startup warning, added backend support for the analytics `range` query parameter, made the API return JSON numbers for `Decimal` values, fixed the CRM interaction endpoint, and introduced a full pytest-based test suite covering all major apps. All backend tests pass.

---

## Backend Changes

### `config/settings/base.py`
- Removed `ckeditor` and `ckeditor_uploader` from `INSTALLED_APPS`.
- Removed `CKEDITOR_CONFIGS`, `CKEDITOR_UPLOAD_PATH`, and `CKEDITOR_IMAGE_BACKEND`.
- Added `'COERCE_DECIMAL_TO_STRING': False` to `REST_FRAMEWORK` defaults so the dashboard receives numeric decimals.

### `requirements/base.txt`
- Removed unused packages:
  - `django-ckeditor`
  - `django-smart-selects`
  - `django-ratelimit`
  - `django-stdimage`
  - `django-admin-sortable2`
  - `bleach`
  - `celery`

### `requirements/development.txt`
- Removed `django-debug-toolbar`.
- Added `pytest-freezegun==0.4.2` for time-frozen analytics tests.

### `apps/analytics/views.py`
- Added `range` query param support (`30d`, `90d`, `all`).
- Computed `start_date` and `previous_start_date` from `timezone.now().date()`.
- Filtered summary aggregations and top-products / city-sales / monthly-sales by the selected window.
- Added `revenue_trend` comparing current window vs previous window.
- Kept the `inventory` endpoint as a global low-stock report.

### `apps/crm/serializers.py`
- Made `customer` not required on `CustomerInteractionSerializer` (`extra_kwargs = {'customer': {'required': False}}`).
- The viewset action binds the URL `customer_pk` to the instance before saving, preventing client spoofing.

### Test suite
- Created `backend/pytest.ini` with `DJANGO_SETTINGS_MODULE=config.settings.development` and `--reuse-db`.
- Created `backend/conftest.py` with reusable `api_client`, `admin_user`, `admin_client`, and `regular_user` fixtures.
- Added per-app factory modules:
  - `apps/accounts/factories.py`
  - `apps/cart/factories.py`

  - `apps/crm/factories.py`
