## Backend Fixes

### B1. Remove dead backend dependencies (HIGH)

**Problem:** Several packages in `requirements/base.txt` are no longer imported anywhere, and `django-ckeditor` still loads a CKEditor 4 widget that prints a security warning on startup.

**Fix:**
- Remove from `requirements/base.txt`:
  - `django-ckeditor`
  - `django-smart-selects`
  - `django-ratelimit`
  - `django-stdimage`
  - `django-admin-sortable2`
  - `bleach`
  - `celery`
- Remove from `requirements/development.txt`:
  - `django-debug-toolbar`
- Remove `ckeditor`/`ckeditor_uploader` from `INSTALLED_APPS` and drop `CKEDITOR_CONFIGS` / `CKEDITOR_UPLOAD_PATH` / `CKEDITOR_IMAGE_BACKEND` from `config/settings/base.py`.
- Keep `django-filter` and `pillow` (still used).

### B2. Serve JSON numbers for decimals (HIGH)

**Problem:** DRF coerces `Decimal` values to strings by default. The analytics dashboard uses `.toFixed()` on totals and receives strings, which breaks formatting.

**Fix:** Add `'COERCE_DECIMAL_TO_STRING': False` to `REST_FRAMEWORK` defaults in `config/settings/base.py`.

### B3. Analytics `range` query parameter (HIGH)

**File:** `backend/apps/analytics/views.py`

**Fix:**
- Read `request.query_params.get('range')`.
- Accept `'30d'`, `'90d'`, and `'all'` (default).
- Compute `start_date` / `previous_start_date` from `timezone.now().date()`.
- Filter orders by `created_at__date__gte=start_date`.
- Return `summary` totals limited to the selected window and a `revenue_trend` comparing current window vs previous window.
- Keep `inventory` endpoint unchanged (global low-stock report).

### B4. CRM `add_interaction` serializer fix (MEDIUM)

**File:** `backend/apps/crm/serializers.py`

**Problem:** `CustomerInteractionSerializer` required `customer`, so the `add_interaction` action (which receives `customer_pk` from the URL) rejected requests that omitted it.

**Fix:** Add `extra_kwargs = {'customer': {'required': False}}` and set `customer` from the URL keyword argument in the viewset action.
