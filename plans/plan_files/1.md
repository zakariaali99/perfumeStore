## Phase 1 — `products` App (Root Unblocker)

**Goal:** Reconcile models with migrations, fix serializer crashes, register signals, optimize queries.

### 1A. `backend/apps/products/models.py`
- Remove `category = ForeignKey(Category, CASCADE)`
- Add `categories = ManyToManyField(Category, blank=True, verbose_name="الفئات")`
- Remove `concentration` field
- Remove `longevity_rating`, `sillage_rating`
- Add `occasion = TextField(blank=True, help_text="ex: ليلي, حفلات, كلاسيكي", verbose_name="مناسب لـ")`
- Add `vibe = TextField(blank=True, help_text="ex: قوي, دافئ, رجولي", verbose_name="مزاج العطر")`
- Change `gender` to `max_length=10`, choices `[('men','رجالي'),('women','نسائي'),('unisex','للجنسين')]`, default `'unisex'`
- Change `brand` to `null=True, blank=True, on_delete=SET_NULL`
- Change `main_image` to `null=True, blank=True`
- Change `description` to `blank=True, default=""`
- Change `story` to `blank=True, default=""`
- Change `fragrance_families` to `blank=True`
- Add `Product.Meta.ordering = ['-created_at']`
- Add `Brand.slug = SlugField(allow_unicode=True, blank=True, unique=True)`
- Change `Brand.logo` to `blank=True`
- Add `Brand.Meta.ordering = ['name_ar']`
- Add `ProductVariant.name = CharField(max_length=100, blank=True, verbose_name="اسم العبوة")`
- Change `ProductVariant.size_ml` to `null=True, blank=True`
- Change `ProductVariant.cost_price` to `null=True, blank=True`
- Change `ProductVariant.sku` to `blank=True`
- Add `@property discount_percentage` on `ProductVariant`

### 1B. `backend/apps/products/serializers.py`
- `ProductListSerializer`: change `category` → `categories` (many); add `occasion`, `vibe`
- `ProductListSerializer.get_min_price`: use annotation `getattr(obj, 'min_price', None)`
- `ProductDetailSerializer`: change `category` → `categories` (many); add `occasion`, `vibe`
- `ProductVariantSerializer`: add `name`, `cost_price`, `barcode`, `low_stock_threshold`
- Add `AdminProductCreateSerializer` with writable flat FKs + nested variants

### 1C. `backend/apps/products/views.py`
- `filterset_fields`: change `'category'` → `'categories'`
- `get_queryset`: replace `.select_related('category')` with `.prefetch_related('categories')`; add `.distinct()`
- `related` action: filter by `categories__in=product.categories.all()`; add prefetches
- `AdminProductViewSet`: use writable serializer for writes; add prefetches
- `AdminVariantViewSet`: add `.select_related('product')`
- Add `AdminBrandViewSet` and `AdminCategoryViewSet` for the frontend dashboard

### 1D. `backend/apps/products/apps.py`
- Add `ready()` that imports `products.signals`

### 1E. `backend/apps/products/admin.py`
- Register `Category`, `Brand`, `FragranceFamily`, `Product` (with inlines), `ProductVariant`
